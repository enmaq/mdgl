# MDGL for C (0.3.0 release candidate in source: parser, checker, evaluator, renderer, adapter, player)

0.3.0 release candidate in source, not yet published. In the final integration (2026-10-10 UTC) it passed, together with the four other adapters, the 83-fixture corpus (63 normative + 20 non-normative) under the bounded protocol-v1 profile (current corpus: 86 fixtures, 64 normative + 22 non-normative; independent verification pending); that is bounded evidence, not a universal SPEC certification. Limitation: the library builds with `_GNU_SOURCE`, and the locale-dependent test is skipped when `de_DE.UTF-8` is not installed.

C99, dependency-free (libm only) parser and semantic checker for
[MDGL](https://github.com/enmaq/mdgl) 0.1, ported from the Go reference
(`parse` + `check`). The first diagnostic equals Go's `line:column: message`
(one-based UTF-8 byte columns). Declared version is `0.3.0` (release candidate); the
published 0.2.0 C source tarball was a limited header/resource seed only and does not have
anything described here.

**Done:** lexing (Go quoted escapes, byte columns, finite non-exponent
decimals, `deg`/`rad`/`s`/`%` suffixes), parsing, scene/actor/action checking
(order, limits, duplicates, unknown names with did-you-mean, parents incl.
forward refs and cycles, shape and verb arguments, timing/period/repeat/
fallback, overlap, grapheme/control-character text limits).

**Evaluator and renderer (`mdgl_render.c`):** ported from the Go reference. Pure, seekable
`mdgl_frame` / `mdgl_frame_ns` / `mdgl_fallback_frame` / `mdgl_scene_active`: nine actions and the six
easings, nanosecond-rounded time, repeat/Done/fallback, parent transforms/opacity/reveal, z then
declaration paint order, braille text/rect/circle/wire cube, RGB source-over blending with
`#rrggbb`, wide graphemes as U+FFFD, one grapheme per cell (zero width keeps its cell, first
non-mark rune). `type` uses the exact integer `floor(elapsed_ns / per_char_ns)` with no epsilon
(the Go reference adds 1e-9; the two agree on every differential case).

**Conformance adapter (`mdgl_adapter.c`, executable `mdgl_adapter`):** NDJSON protocol v1
(`conformance/PROTOCOL.md`), strict RFC 8259 reader with UTF-8 validation, 2 MiB line cap (longer
line: `bad_request`, rest of the line discarded), exact mathematical integers for `v`/`time_ns`/
`width`/`height` (`1.0`, `1e9`, `-0` accepted; `9007199254740991.1`, `-1`, `1e400`, booleans rejected),
lone-surrogate and invalid-UTF-8 handling, final unterminated line answered then exit 0, `done`
only on non-fallback frames, `invalid_source` with diagnostics. Duplicate JSON members: the last
wins; nesting deeper than 256 is `bad_request`; unknown members are ignored. Transport tests:
`python3 test_adapter.py ./mdgl_adapter`. The final-integration runner result for this adapter is bounded evidence, not a conformance certification.

**Not done:** status canvas; Windows/MSVC build is untested.

**Unicode:** grapheme clusters (1024 limit, text width, `type` duration) follow
rivo/uniseg v0.4.7 = Unicode 15.0.0 UAX29 (GB3-GB13, GB999; no GB9c, as in the
reference). `mdgl_unicode.h` is generated by `gen_unicode.py` from the uniseg
tables (MIT, (c) 2019 Oliver Kuederle; Unicode data under the Unicode License),
including its East Asian Width and emoji-presentation width rules.
`mdgl_grapheme_step` is exported for differential testing.

**Decimals and locale:** the MDGL grammar is validated first, then the literal is
copied into a private buffer with `.` replaced by the current locale's decimal
separator (any length), converted with `strtod` and accepted only if `strtod`
consumed the whole buffer. The library reads the locale (`localeconv`) and
never calls `setlocale`. Constraints: another thread calling `setlocale` while a
check runs is a data race the library cannot prevent; rounding is the C
library's `strtod` (correctly rounded on glibc/musl/UCRT; matches Go's
`ParseFloat` for the allowed grammar there); a multi-character separator is
handled by buffer sizing but no installed glibc locale has one to exercise.

**Memory:** every allocation failure becomes an `out of memory` diagnostic
(token buffer included); attribute/argument key checks have no fixed limit.

**ABI changes vs the published 0.2.0 subset:** `mdgl_diag_t.message` is 512
bytes (was 128); `mdgl_check*` return 0 or 1 diagnostics (first diagnostic, as
Go); new scene/actor/action types, `mdgl_parse_n`, `mdgl_scene_check`,
`mdgl_scene_free`, `mdgl_grapheme_step`, the `mdgl_frame*` API and `mdgl_cell_t`/`mdgl_frame_t`; the library now links libm and builds with `_GNU_SOURCE` for `M_PI`. `mdgl_unicode.h` also carries Go `IsMark`/`IsPrint` tables (the old message-quoting approximation is gone). Third-party licences: `THIRD_PARTY_NOTICES.md`.

**Tests (targeted):** `test_check.c` (~150 exact-diagnostic and cluster-count
cases), `test_locale.c <locale>` (skips with 77 if unavailable), `test_oom.c`
(failure injection, GNU ld). Regenerate tables: `python3 gen_unicode.py
$(go list -m -f '{{.Dir}}' github.com/rivo/uniseg) > mdgl_unicode.h`.

## Command line and terminal player

```sh
cmake -S . -B build && cmake --build build
cmake --install build --prefix "$HOME/.local"      # installs bin/mdgl, lib/libmdgl.a, include/mdgl*.h, docs
mdgl play ../examples/text.mdgl                     # animate in a terminal; Ctrl+C stops
mdgl check FILE | mdgl frames FILE --at 0,1.5 | mdgl --help
```

`mdgl play` runs the scene at its own `fps` using the absolute monotonic clock (elapsed = now - start,
never accumulated ticks; a late tick drops frames), redraws only changed cells (foreground and background
colours included) inside DEC synchronized-output (mode 2026) blocks, stops when the evaluator reports done
(`repeat=infinite` runs until interrupted), and always restores the terminal (sync off, attributes reset,
cursor shown, newline) on done, Ctrl+C/SIGTERM and write errors. It never clears the screen. When stdout is not a terminal, or `NO_COLOR` or
`MDGL_REDUCED_MOTION` is set and non-empty, it prints the scene's fallback frame once as plain text, with no
timer and no escape sequences. Cell data never reaches the terminal as a control byte.
Exit status: 0 ok, 1 invalid scene (`FILE:LINE:COL: MESSAGE` on stderr), 2 usage, unreadable file or
write error, 130 interrupted. POSIX only for animation (Windows prints the plain frame). Library use:
`mdgl_play.h` (`mdgl_play`, `mdgl_play_plain`) takes an injectable clock, writer, sleeper and interrupt test;
`test_play.c` drives it deterministically and `test_play_pty.py` runs the real binary on a pseudo-terminal.

## Quick start: render one frame

Requires a C99 compiler and CMake 3.16+. From the `c/` directory (the default scene path is relative to it):

```sh
cmake -S . -B build && cmake --build build --target mdgl_render
./build/mdgl_render                      # ../examples/text.mdgl at t=4s
./build/mdgl_render --time 1.5           # another instant (seconds, >= 0)
./build/mdgl_render --fallback           # the scene's fallback frame
./build/mdgl_render path/to/scene.mdgl   # your own scene; "-" reads stdin
```

The frame goes to stdout as plain text (colours are in the API but not printed); a status line goes to
stderr. Exit status: 0 ok, 1 the scene has a diagnostic (`FILE:LINE:COL: MESSAGE` on stderr), 2 usage or
I/O error. The source is `examples/render.c` (about 100 lines): `mdgl_parse_n`, `mdgl_scene_check`,
`mdgl_frame` / `mdgl_fallback_frame`, then `mdgl_frame_free` and `mdgl_scene_free`.

## API (`mdgl.h`)

- `mdgl_parse_n(src, len, &diag)` -> scene or `NULL` (diag filled).
- `mdgl_scene_check(scene, &diag)` -> 0 ok / 1 diagnostic; fills derived fields.
- `mdgl_scene_free(scene)`: frees the scene and everything reachable from it.
- `mdgl_check_n` / `mdgl_check`: parse + check, as before (length-aware variant keeps NUL bytes).

Ownership: the scene owns all memory; the source buffer is not retained.

```sh
cmake -S . -B build && cmake --build build && ctest --test-dir build
```
